# Encrypted File System (EFS)

A Java application developed as part of the Cryptography and Computer Security course.

The project explores the application of cryptographic concepts in file management and data protection.

## Technologies

- Java
- Cryptography

## Overview

The project focuses on an encrypted file system and explores concepts related to file security, data protection, and cryptographic operations.

## Project Purpose

This project was developed to gain practical experience with Java programming and the application of cryptographic concepts in software development.
